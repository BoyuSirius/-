# 山东铁塔未知资产发现测试

一个用于「未知资产发现」功能演练/测试的轻量小项目，包含前端页面、配置文件和可选的后端 Mock 服务。

## 目录结构

```
test/
├── index.html   # 前端页面（资产扫描、统计、导出），双击即可运行
├── config.js    # 配置文件（目标网段 / 端口 / 已知资产指纹库）
├── server.js    # 可选：本地 Mock 后端，提供资产发现 HTTP 接口
└── README.md
```

## 运行方式

### 方式一：纯前端（推荐，零依赖）
直接双击 `index.html`，在浏览器打开即可。

页面内置了模拟扫描数据，用于界面演示，无需安装任何服务。

### 方式二：本地 Mock 后端（前后端联调）
需要 Node.js，无需安装任何第三方依赖：

```bash
node server.js
```

浏览器访问 `http://127.0.0.1:3000`。

提供接口：

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/health` | GET | 健康检查 |
| `/api/config` | GET | 获取配置 |
| `/api/scan/discover` | POST | 资产发现（核心） |

## 配置说明（config.js）

| 项 | 示例 | 说明 |
| --- | --- | --- |
| `SCAN_CONFIG.targets` | `1.1.1.1`、`192.168.0.9`、`192.168.0.0/24` | **内网 IP / 网段**，扫描目标 |
| `SCAN_CONFIG.commonPorts` | `22,80,443,3389,...` | 端口探测范围 |
| `SCAN_CONFIG.concurrency` | `50` | 探测并发数 |
| `SCAN_CONFIG.enableActiveScan` | `true` | 是否启用主动扫描 |
| `KNOWN_ASSETS` | 列表 | **已备案资产指纹库**，命中者标记为「已备案」，未命中者为「未知资产」 |

> 场景示例：`1.1.1.1` 未在任何已知资产库中出现，将被识别为不确定/未知资产；`192.168.0.9` 已在指纹库中，标记为已备案。

## 后续接入真实扫描引擎

现阶段的扫描结果是 Mock 数据。接入真实引擎时：

1. 后端：在 `server.js` 的 `POST /api/scan/discover` 中，将 `MOCK_POOL` 换成对真实扫描引擎（Nmap / 自定义探测器）的调用；
2. 前端：将 `index.html` 里的前端 `MOCK_POOL` 与 `KNOWN_IPS`，改为对 `/api/scan/discover` 的 `fetch` 请求。

## 安全提示

- 本项目仅用于**已授权**的内网资产盘点测试，请勿对未授权目标发起扫描。
